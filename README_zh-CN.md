# RiskMoE

## 面向金融风险分类的图引导稀疏专家模型

RiskMoE 是一个用于企业披露文本句级金融风险分类的稀疏混合专家模型。模型通过将文本语义与时间对齐的结构化背景信息结合，提高复杂风险表达下的分类能力与置信度可靠性。

## 核心方法

RiskMoE 包含以下模块：

- Transformer 文本编码器；
- 图条件化 Top-2 稀疏专家路由；
- 四个可路由专家；
- 一个始终激活的共享专家；
- 结构信息到文本表示的交叉注意力；
- 门控融合分类模块。

结构侧信息包括：

- exact-CIK 历史 SEC filing/XBRL 属性；
- 行业信息；
- 地理位置；
- 披露年份；
- 文件章节信息。

结构信息仅用于条件路由和融合，不替代原始文本语义。

## 实验结果

固定数据划分：

- 训练集：125,118 条；
- 验证集：347 条；
- 测试集：600 条。

测试结果：

|模型|Micro-F1|Macro-F1|ECE|
|-|-:|-:|-:|
|Text-only MoE|0.6633|0.6626|0.2273|
|RiskMoE|0.7150|0.7150|0.0761|
